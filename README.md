# Mad Libs Generator

A fun, interactive command-line Mad Libs game implemented in Python. 

## Description

This project allows users to choose from three distinct storyline templates (The Hospital Visit, Camping Trip, or Enchanted Castle) or pick a random one. The program prompts the user for various parts of speech (nouns, verbs, adjectives, etc.) and dynamically injects them into the chosen template to create a unique, humorous story.

## Features
* **Three Handcrafted Templates:** Distinct themes with tailored vocabulary prompts.
* **Randomizer Option:** Lets the computer surprise you with a story template selection.
* **Robust Error Handling:** * Prevents the application from crashing on invalid menu choices.
  * Validates text inputs to guarantee fields are not submitted completely empty.

### Prerequisites
